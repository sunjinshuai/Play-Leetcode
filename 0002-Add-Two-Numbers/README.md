# 2. 两数相加

[力扣题目](https://leetcode.cn/problems/add-two-numbers/) · [Java 源码](Java/Solution.java)

## 题目与数字顺序

两个非空链表分别表示两个非负整数，每个节点保存一位数字，按个位、十位、百位的顺序存储。返回同样按逆序存储的和。

```text
5 → 6 → 4
↑   ↑   ↑
个位 十位 百位

表示：5 + 60 + 400 = 465，而不是 564。
```

例如 `2 → 4 → 3` 与 `5 → 6 → 4` 相加，表示 `342 + 465 = 807`，结果为 `7 → 0 → 8`。

## 思路：先按位求和，再统一进位

这份解法直接复用输入节点，以 `l1` 为结果链表，不使用辅助头节点。

1. 第一遍遍历：对应位置相加，暂时允许节点值大于等于 10；如果 `l1` 较短，把 `l2` 剩余部分接上。
2. 第二遍遍历：调用 `merge`，从个位开始逐个处理进位。

例如 `27 + 15`：

```text
l1：7 → 2
l2：5 → 1

第一遍：12 → 3    （7 + 5 = 12，2 + 1 = 3）
第二遍： 2 → 4    （12 留下个位 2，向后进位 1）
```

第一遍的第二个节点是 `3`，不是 `4`：进位尚未加入，只有执行 `merge` 后才变成 `4`。

## 第一遍：addTwoNumbers

### 1. 用指针记录当前位置

```java
ListNode head1 = l1;
ListNode head2 = l2;
```

这两行不创建新节点。`head1`、`head2` 分别指向输入链表的头，随后向后移动；`l1` 始终保留结果的起点。

修改 `head1.val` 会修改它所指向的原节点，因此也会改变 `l1` 链表中的值。

### 2. 对应节点相加

```java
while (head1 != null) {
    if (head2 != null) {
        head1.val += head2.val;
        head2 = head2.next;
    }
    // 检查是否需要接上 l2 的剩余部分。
    // 然后移动 head1。
}
```

当 `head2` 有节点时，将其值加到 `head1`，再让 `head2` 前进一步。如果 `l2` 先走完，就保留 `l1` 剩余节点的值，相当于对应位置加 0。

### 3. l1 较短时，接上 l2 剩余节点

```java
if (head1.next == null && head2 != null) {
    head1.next = head2;
    break;
}
head1 = head1.next;
```

这里的 `head2` 已经移动过，指向的是尚未参与相加的节点。

以 `2 + 345` 为例：

```text
开始：l1 = 2，l2 = 5 → 4 → 3

相加并移动 head2 后：
head1 → [7]
head2 → [4] → [3]

执行 head1.next = head2：
l1 → [7] → [4] → [3]
```

`l1` 已没有更多数字，剩余位相当于加 0，所以可以直接复用后面的节点。`break` 退出第一遍循环，随后仍会执行 `merge(l1)`，处理可能传入这段链表的进位。

两条链表等长时，最终 `head2` 为 `null`，无需拼接。

## 第二遍：merge 处理进位

### 1. 当前节点保留个位，下一节点加 1

```java
if (node.val >= 10) {
    node.val = node.val % 10;
    if (node.next == null) {
        node.next = new ListNode(0);
    }
    node.next.val += 1;
}
node = node.next;
```

例如 `12 → 3`：

```text
12 % 10 = 2： 2 → 3
下一节点加 1：2 → 4
```

进位要加到下一节点原来的值上，不能直接把下一节点改成 1。

为什么每次只进位 1？题目保证原节点值在 0～9，两个数字相加最多为 18，再加前一位传来的 1，最多为 19。因此进位只可能是 0 或 1。

### 2. 最后一位进位时创建节点

例如 `9 + 1`，第一遍得到单个节点 `10`：

```text
当前节点取余： [0]
创建下一节点： [0] → [0]
下一节点加 1：[0] → [1]
```

`new ListNode(0)` 先创建一个值为 0 的节点，再通过 `node.next.val += 1` 接收进位。这个节点属于答案，和用于占位的辅助头节点不同。

### 3. 连续进位

例如 `99 + 1`，第一遍得到 `10 → 9`：

```text
处理第一个节点：0 → 10
处理第二个节点：0 → 0 → 1
```

最终表示 100。`node = node.next` 会继续访问刚刚接收到进位的节点，因此连续进位不会遗漏。

当 `node` 变为 `null`，所有节点和进位都处理完，`merge` 结束；`addTwoNumbers` 返回 `l1`。

## 边界示例

| 相加的整数 | 输入链表 | 返回链表 | 覆盖情况 |
| --- | --- | --- | --- |
| 0 + 0 | `[0]`、`[0]` | `[0]` | 零、无进位 |
| 27 + 15 | `[7,2]`、`[5,1]` | `[2,4]` | 等长、中间进位 |
| 32 + 4 | `[2,3]`、`[4]` | `[6,3]` | l1 较长 |
| 2 + 345 | `[2]`、`[5,4,3]` | `[7,4,3]` | l2 较长 |
| 9 + 1 | `[9]`、`[1]` | `[0,1]` | 末位新增节点 |
| 99 + 1 | `[9,9]`、`[1]` | `[0,0,1]` | 连续进位 |
| 1 + 99 | `[1]`、`[9,9]` | `[0,0,1]` | 拼接后连续进位 |

## 复杂度与使用边界

设两个链表长度分别为 `m`、`n`。

- 时间复杂度：`O(max(m, n))`。两遍遍历仍是线性时间。
- 额外空间复杂度：`O(1)`。复用输入节点，只使用固定数量的指针，最高位进位时最多新增一个节点。

源码使用力扣提供的 `ListNode`，可直接提交 `Solution`。输入遵循题目约束：链表非空、每个节点值为 0～9。

该解法会修改 `l1`。当 `l1` 较短时，结果还会共享 `l2` 的剩余节点，后续进位可能修改这些节点。如果业务要求保留输入链表，应另建结果链表。
