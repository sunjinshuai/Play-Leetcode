# 3. 无重复字符的最长子串

给定字符串 `s`，返回其中最长的无重复字符子串的长度。子串中的字符必须在原字符串中连续出现。

[力扣原题](https://leetcode.cn/problems/longest-substring-without-repeating-characters/) · [Java 源码](Java/Solution.java) · [Swift 源码](Swift/Solution.swift)

| 输入 | 返回值 | 一个最长子串 |
| --- | ---: | --- |
| `"abcabcbb"` | 3 | `"abc"` |
| `"bbbbb"` | 1 | `"b"` |
| `"pwwkew"` | 3 | `"wke"`（`"kew"` 同样符合） |
| `""` | 0 | `""` |

## 滑动窗口

用 `left` 和 `right` 表示窗口的两个端点，集合 `seen` 记录窗口中的字符。右端每读入一个字符，先检查它是否已在集合里。如果重复，就从左端逐个移除字符，直到旧的同名字符离开窗口。再加入当前字符，用 `right - left + 1` 更新最大长度。

| 读入位置 | 当前字符 | 调整后的窗口 | 历史最长 |
| ---: | :---: | --- | ---: |
| 0 | `p` | `p` | 1 |
| 1 | `w` | `pw` | 2 |
| 2 | `w` | `w`（依次移出 `p` 和旧的 `w`） | 2 |
| 3 | `k` | `wk` | 2 |
| 4 | `e` | `wke` | 3 |
| 5 | `w` | `kew` | 3 |

下标 2 说明了为什么要用 `while`。第一次移出 `p` 后，旧的 `w` 还在窗口里。每轮只把左端推进到窗口刚好合法的位置，因此得到的是以当前 `right` 结尾的最长合法子串。取所有结尾对应长度的最大值即可。

## 复杂度

- 时间为 O(n)。每个位置最多入窗一次、出窗一次，集合操作平均为 O(1)。
- Java 额外空间为 O(min(n, |Σ|))，其中 |Σ| 为字符集大小。Swift 先用 `Array(s)` 转为可用整数下标访问的字符数组，额外空间为 O(n)。
