# 20. 有效的括号

给定一个只包含 `()`、`{}`、`[]` 六种字符的字符串 `s`，判断括号类型和闭合顺序是否正确，每个右括号都必须有对应的左括号。

[力扣题目](https://leetcode.cn/problems/valid-parentheses/) · [Java 源码](Java/Solution.java) · [Objective-C 源码](OC/0020-Valid-Parentheses.xcodeproj)

## 示例

| s | 返回值 | 说明 |
| --- | --- | --- |
| `"()"` | true | 一对括号正确闭合 |
| `"()[]{}"` | true | 多组括号依次闭合 |
| `"{[]}"` | true | 内层先闭合，外层后闭合 |
| `"([])"` | true | 不同类型可以嵌套 |
| `"(]"` | false | 左右括号类型不匹配 |
| `"([)]"` | false | 数量相等，但闭合顺序错误 |
| `")("` | false | 第一个右括号没有对应的左括号 |
| `"(()"` | false | 遍历结束仍有左括号未闭合 |

题目约束为 `1 <= s.length <= 10000`，且输入只包含上述六种括号。此实现对空字符串也返回 `true`，但空字符串不属于当前题目的输入范围。

## 思路：栈

**最近出现、尚未匹配的左括号，必须最先闭合。** 这正好符合栈的后进先出特性。

栈中只保存尚未匹配的左括号，栈顶表示当前最内层、等待闭合的括号。

1. 遇到左括号，压入栈中。
2. 遇到右括号，如果栈为空，说明没有左括号可以与它匹配，立即返回 `false`。
3. 栈不为空时，用 `peek()` 查看栈顶。类型匹配则用 `pop()` 弹出；类型不同则立即返回 `false`。
4. 遍历结束后，只有栈为空，才表示所有左括号都已闭合。

不能只统计各类括号的数量。例如 `([)]` 中每种括号数量都相等，但遇到 `)` 时，栈顶是 `[`，此时应该先出现 `]`，所以字符串无效。

## Java 实现

保留给定的 `Stack<Character>`、先查看栈顶再匹配弹出的写法。以下代码省略本地源码中的 `package com.company;`，可直接用于力扣提交。

```java
import java.util.Stack;

public class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<Character>();
        for (int i = 0; i < s.length(); i++) {
            Character tempChar = s.charAt(i);
            if (tempChar == '(' || tempChar == '{' || tempChar == '[') {
                stack.push(tempChar);
            } else {
                if (stack.size() == 0) {
                    return false;
                }
                Character lastChar = stack.peek();
                if (isPairMatch(lastChar, tempChar)) {
                    stack.pop();
                } else {
                    return false;
                }
            }
        }
        return stack.isEmpty();
    }

    public boolean isPairMatch(Character leftPair, Character rightPair) {
        return (leftPair == '(' && rightPair == ')')
                || (leftPair == '{' && rightPair == '}')
                || (leftPair == '[' && rightPair == ']');
    }
}
```

## 为什么选择栈？

以 `{[()]}` 为例，左括号的出现顺序是 `{ → [ → (`，对应的闭合顺序却必须反过来：`) → ] → }`。

最后出现的左括号需要最先被匹配，这就是后进先出。可以把栈理解成一摞盘子：新盘子放在最上面，取盘子时也先取最上面的。

| 方法 | 含义 | 是否改变栈 |
| --- | --- | --- |
| `push(value)` | 把元素放到栈顶 | 是 |
| `peek()` | 查看栈顶元素 | 否 |
| `pop()` | 移除并返回栈顶元素 | 是 |
| `isEmpty()` | 判断栈是否为空 | 否 |

读取完 `{[(` 时，栈的状态如下：

```text
栈顶 → (
       [
栈底 → {
```

栈顶的 `(` 就是下一个右括号必须匹配的左括号。

## 逐段讲解

### 1. 创建栈并遍历字符串

```java
Stack<Character> stack = new Stack<Character>();
for (int i = 0; i < s.length(); i++) {
    Character tempChar = s.charAt(i);
```

栈保存已经出现、但尚未匹配的左括号。循环从左到右依次读取每个字符。

`charAt(i)` 返回基本类型 `char`，赋给 `Character` 时会自动装箱。此处也可以使用 `char tempChar`，不影响算法逻辑。

### 2. 遇到左括号：入栈等待匹配

```java
if (tempChar == '(' || tempChar == '{' || tempChar == '[') {
    stack.push(tempChar);
}
```

左括号出现时，还没有遇到对应的右括号，因此先保存起来。

例如依次读取 `{` 和 `[` 后，栈为 `{ [`。下文除竖直图示外，都按照“栈底 → 栈顶”的顺序展示，最右侧是栈顶。

### 3. 遇到右括号：先检查是否存在可匹配的左括号

```java
if (stack.size() == 0) {
    return false;
}
```

题目保证输入只包含六种括号，因此进入 `else` 就表示当前字符是右括号。

此时如果栈为空，说明没有尚未匹配的左括号可以与它配对。例如 `")("` 的第一个字符就是 `)`，直接返回 `false`。后面即使出现 `(` 也无法补救，因为对应的左括号必须先出现。

空栈检查也避免了调用 `peek()` 时抛出异常。`stack.size() == 0` 可以等价地写成 `stack.isEmpty()`。

### 4. 查看栈顶，匹配成功后弹出

```java
Character lastChar = stack.peek();
if (isPairMatch(lastChar, tempChar)) {
    stack.pop();
} else {
    return false;
}
```

`peek()` 只读取栈顶，不会将其移除。假设栈为 `{ [`，当前字符是 `]`，那么 `lastChar` 就是 `[`。

两者匹配成功后，调用 `pop()` 移除 `[`，栈变为 `{`。这一对括号已经处理完毕，右括号无需入栈。

如果类型不匹配，立即返回 `false`。例如 `([)]`：

| 当前字符 | 操作 | 栈 |
| --- | --- | --- |
| `(` | 入栈 | `(` |
| `[` | 入栈 | `( [` |
| `)` | 与栈顶 `[` 不匹配，返回 `false` | `( [` |

不能跳过栈顶 `[` 去寻找下面的 `(`。`[` 是后来打开的内层括号，必须先闭合；跳过它会导致括号交叉，违反嵌套顺序。

### 5. 配对函数只接受三种组合

```java
public boolean isPairMatch(Character leftPair, Character rightPair) {
    return (leftPair == '(' && rightPair == ')')
            || (leftPair == '{' && rightPair == '}')
            || (leftPair == '[' && rightPair == ']');
}
```

每组内部用 `&&`，要求左右字符同时满足条件；三组之间用 `||`，满足任意一组即可。

| leftPair | rightPair | 返回值 |
| --- | --- | --- |
| `(` | `)` | true |
| `{` | `}` | true |
| `[` | `]` | true |
| `[` | `)` | false |

这里 `Character` 与 `'('` 这样的基本类型 `char` 字面量比较，会自动拆箱后比较字符值，不是在比较两个 `Character` 对象的引用，因此使用 `==` 正确。

### 6. 遍历结束后，还要检查是否有左括号剩余

```java
return stack.isEmpty();
```

前面的检查只保证每个已经遇到的右括号都有正确的匹配，不能保证所有左括号都已闭合。

以 `s = "(()"` 为例：

| 当前字符 | 操作 | 操作后的栈 |
| --- | --- | --- |
| `(` | 入栈 | `(` |
| `(` | 入栈 | `( (` |
| `)` | 匹配成功，弹出一个 `(` | `(` |

遍历过程中没有出现类型不匹配，但最后还剩一个 `(`，因此返回 `false`。如果这里直接返回 `true`，就会错误接受 `"("`、`"(("`、`"(()"` 等字符串。

## 完整示例：栈的变化

以 `s = "{[()]}"` 为例：

| 下标 | 当前字符 | 判断与操作 | 操作后的栈 |
| --- | --- | --- | --- |
| 0 | `{` | 左括号入栈 | `{` |
| 1 | `[` | 左括号入栈 | `{ [` |
| 2 | `(` | 左括号入栈 | `{ [ (` |
| 3 | `)` | 与栈顶 `(` 匹配，弹出 | `{ [` |
| 4 | `]` | 与栈顶 `[` 匹配，弹出 | `{` |
| 5 | `}` | 与栈顶 `{` 匹配，弹出 | 空 |

整个过程没有发生不匹配，遍历结束时栈为空，返回 `true`。

## 三种失败情况

| 错误类型 | 示例 | 检查位置 |
| --- | --- | --- |
| 右括号没有对应的左括号 | `")"`、`"())"` | 遇到右括号时，栈为空 |
| 类型或嵌套顺序错误 | `"(]"`、`"([)]"` | 当前右括号与栈顶不匹配 |
| 左括号未完全闭合 | `"("`、`"(()"` | 遍历结束，栈不为空 |

只有这三种情况都没有发生，字符串才有效。判断过程中始终保持一个规则：**栈顶就是下一个右括号必须匹配的左括号。**

## 复杂度

- 时间复杂度：`O(n)`。遍历一次，每个字符最多入栈和出栈各一次。
- 额外空间复杂度：`O(n)`。最坏情况下全是左括号，栈需要保存全部字符。
