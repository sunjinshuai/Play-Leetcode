# 20. 有效的括号

## 题目描述

给定一个只包含 `(`、`)`、`{`、`}`、`[` 和 `]` 的字符串，判断括号是否正确配对。

有效字符串满足以下条件。

- 左括号必须用相同类型的右括号闭合。
- 左括号必须以正确的顺序闭合。

仓库示例也将空字符串视为有效。

## 示例

### 示例 1

```text
输入: "()"
输出: true
```

### 示例 2

```text
输入: "()[]{}"
输出: true
```

### 示例 3

```text
输入: "(]"
输出: false
```

### 示例 4

```text
输入: "([)]"
输出: false
```

### 示例 5

```text
输入: "{[]}"
输出: true
```

## 解题思路

1. 遍历字符串，遇到左括号时入栈。
2. 遇到右括号时，检查栈顶是否为对应的左括号。匹配时弹出栈顶，栈空或类型不匹配时返回 `false`。
3. 遍历结束后，栈为空时返回 `true`，否则返回 `false`。
