# 21. 合并两个有序链表

将两个按非递减顺序排列的链表合并为一个有序链表，复用输入链表的节点，并返回合并后的头节点。

[力扣题目](https://leetcode.cn/problems/merge-two-sorted-lists/) · [Swift 源码](Swift/Solution.swift) · [Java 源码](Java/Solution.java)

## 递归合并

1. 如果任一链表为空，直接返回另一个链表。两个都为空时返回空。
2. 比较两个头节点，取值较小的节点作为当前结果的头。值相等时，代码取当前调用的第二个头节点。
3. 递归合并选中节点之后的链表与另一条链表，将返回值接到选中节点的 `next`，然后返回该节点。

两条链表各自有序，所以较小的头节点也是当前所有剩余节点中的最小值。每次递归消耗一个节点，直到其中一条链表为空。两份源码均使用力扣提供的 `ListNode`。

## 示例

输入 `[1,2,4]` 和 `[1,3,4]`，输出 `[1,1,2,3,4,4]`。

## 复杂度

设两个链表分别有 `m` 和 `n` 个节点。最坏时间复杂度为 `O(m + n)`，额外空间复杂度为 `O(m + n)`，来自递归调用栈。
