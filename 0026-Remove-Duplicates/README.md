# 26. 删除有序数组中的重复项

## 题目描述

给定升序数组 `nums`，原地删除重复项并保持剩余元素的相对顺序。返回唯一元素的个数 `k`，并将结果写入数组的前 `k` 个位置。

额外空间为 `O(1)`。超出新长度的位置可以保留任意值。

## 示例

### 示例 1

```text
输入：nums = [1, 1, 2]
输出：2，有效前缀为 [1, 2]
```

### 示例 2

```text
输入：nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
输出：5，有效前缀为 [0, 1, 2, 3, 4]
```

## 解题思路

相同的元素在升序数组中相邻。快指针扫描数组，慢指针记录下一个写入位置。保留第一个元素，随后每遇到与上一个保留值不同的元素，就写入并移动慢指针。扫描结束时，写入位置就是新长度。

时间复杂度 `O(n)`，额外空间复杂度 `O(1)`。
