# 27. 移除元素

## 题目描述

给定数组 `nums` 和整数 `val`，原地移除所有等于 `val` 的元素，返回剩余元素的个数 `k`。数组的前 `k` 个位置存放剩余元素，顺序可以改变，其余位置可以保留任意值。

## 示例

### 示例 1

```text
输入：nums = [3, 2, 2, 3], val = 3
输出：2，有效前缀为 [2, 2]
```

### 示例 2

```text
输入：nums = [0, 1, 2, 2, 3, 0, 4, 2], val = 2
输出：5，有效前缀可为 [0, 1, 3, 0, 4]
```

## 解题思路

快指针 `i` 扫描数组，慢指针 `j` 指向下一个写入位置。遇到 `nums[i] != val` 时，将元素写入 `nums[j]` 并递增 `j`。遍历结束后返回 `j`。

时间复杂度 `O(n)`，额外空间复杂度 `O(1)`。
