# 28. 找出字符串中第一个匹配项的下标

## 题目描述

给定字符串 `haystack` 和 `needle`，返回 `needle` 在 `haystack` 中首次出现的下标。下标从 `0` 开始，找不到时返回 `-1`。

仓库中的 `strStr()` 示例使用 Java 的 `indexOf()`，传入空字符串作为 `needle` 时返回 `0`。

## 示例

### 示例 1

```text
输入: haystack = "hello", needle = "ll"
输出: 2
```

### 示例 2

```text
输入: haystack = "aaaaa", needle = "bba"
输出: -1
```
