# 42. 接雨水

给定一排宽度为 1 的柱子，计算下雨后这些柱子之间能存住的总水量。

[力扣题目](https://leetcode.cn/problems/trapping-rain-water/) · [Swift 源码](Swift/Solution.swift)

## 按列计算积水

以 `[4, 1, 3]` 的中间列为例。左墙高 4，右墙高 3，水面超过高度 3 就会从右边流出去。中间的柱子已经占了底下 1 格，剩下的 `3 - 1 = 2` 格才是水。

```text
高度
 4   █
 3   █  ~  █
 2   █  ~  █
 1   █  █  █

█ 表示柱子，~ 表示积水
```

推广到任意第 `i` 列，分别找从数组开头到 `i`、从 `i` 到数组末尾的最高柱。两边都包含第 `i` 列，因此水量至少为 0。

```text
第 i 列的积水 = min(左侧最高, 右侧最高) - height[i]
```

## 双指针

从数组首尾向内扫描。每轮用当前柱高更新 `leftMax` 和 `rightMax`。前者是从开头到 `left` 的最高柱，后者是从 `right` 到末尾的最高柱。

如果 `leftMax < rightMax`，就可以结算 `left`。它的左侧最高值已经确定，右侧也已经找到一根比 `leftMax` 更高的柱子。即使中间还有更高的柱子，水面也只能到 `leftMax`。累加 `leftMax - height[left]`，然后将 `left` 右移一格。否则按同样的道理结算 `right`，包括两侧最高值相等的情况。

循环在指针相遇时结束。考虑最左边的全局最高柱。左指针到达它时，`leftMax < rightMax` 不可能成立，因此左指针不会越过它。右指针到达它且左指针还在它左边时，`leftMax < rightMax` 一定成立，因此右指针也不会越过它。两指针会在这根柱子上相遇，而它的积水为 0。

## 示例

输入 `[4, 2, 0, 3, 2, 5]`，输出 `9`。中间四列的水位都是 4。

```text
柱高    4  2  0  3  2  5
积水    0  2  4  1  2  0
```

## 复杂度

每轮移动一个指针。时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。
