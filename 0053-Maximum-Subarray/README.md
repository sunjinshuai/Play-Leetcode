# 53. 最大子数组和

给定整数数组 `nums`，返回连续、非空子数组的最大和。子数组必须保持原数组中的连续位置，不能跳过中间元素。

[力扣题目](https://leetcode.cn/problems/maximum-subarray/) · [Java 源码](Java/Solution.java)

## 示例与输入范围

| 输入 | 最大和 | 对应子数组 |
| --- | --- | --- |
| `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` | `6` | `[4, -1, 2, 1]` |
| `[5, 4, -1, 7, 8]` | `23` | 整个数组 |
| `[-3, -1, -2]` | `-1` | `[-1]` |
| `[0]` | `0` | `[0]` |

题目保证 `1 <= nums.length <= 100000`，且 `-10000 <= nums[i] <= 10000`。因此可以直接读取 `nums[0]`，累加和使用 Java 的 `int` 足够。本实现按题目约定接收非空数组。

## 累加与舍弃负数前缀

这是 Kadane 算法，时间复杂度为 `O(n)`。遍历时维护两个变量：

- `result`：已经处理过的所有非空子数组中的最大和。
- `count`：用于接上当前元素的累加和；上一轮结束时若为负数，就重置为 `0`。

每轮先执行 `count += nums[i]`。此时 `count` 是以当前元素结尾的非空子数组的最大和，用它更新 `result`，再决定是否清零。

如果一段前缀的和是负数 `s`，后续任意一段的和是 `t`，那么 `s + t < t`。带着这个负数前缀继续向后累加，只会让结果更小，因此可以丢掉它，从下一项重新开始。

例如前面的累加和为 `-4`，下一项是 `5`：继续累加得到 `1`，从 `5` 开始则得到 `5`。

注意，舍弃的条件是**累加和为负数**，不是当前元素为负数。对于 `[4, -1, 2, 1]`，遇到 `-1` 时累加和仍为 `3`，保留这段才能得到后面的最大和 `6`。累加和恰好为 `0` 时，保留或重新开始都不影响最大和。

## Java 实现

```java
public class Solution {
    public int maxSubArray(int[] nums) {
        int result = nums[0];
        int count = 0;

        for (int i = 0; i < nums.length; i++) {
            count += nums[i];

            if (count > result) {
                result = count;
            }

            // 负数前缀只会降低后续子数组的和，因此从下一项重新开始。
            if (count < 0) {
                count = 0;
            }
        }
        return result;
    }
}
```

## 为什么 result 不能初始化为 0

子数组至少包含一个元素。如果 `result = 0`，对于 `[-3, -1, -2]`，任何负数都无法更新答案，最终错误地返回 `0`。

初始化为 `nums[0]`，就以一个合法的非空子数组作为初始答案；后续遇到更大的和再更新。初始化为 `Integer.MIN_VALUE` 也可以，这里使用首元素更直观。

## 为什么先更新答案，再清零

`count = 0` 表示为下一轮重新开始做准备，并不代表已经找到一个和为 `0` 的非空子数组。如果先清零再更新答案，全负数数组仍会错误地返回 `0`。

以 `[-3, -1, -2]` 为例，初始 `result = -3`：

| 当前元素 | 累加后的 count | 更新后的 result | 为下一轮保留的 count |
| --- | --- | --- | --- |
| `-3` | `-3` | `-3` | `0` |
| `-1` | `-1` | `-1` | `0` |
| `-2` | `-2` | `-1` | `0` |

## 从动态规划理解

设 `dp[i]` 为以第 `i` 个元素结尾的非空子数组的最大和。每个位置只有两个选择：从当前元素重新开始，或接在前一个位置的最优子数组后面。

```text
dp[0] = nums[0]
dp[i] = max(nums[i], dp[i - 1] + nums[i])
答案 = 所有 dp[i] 的最大值
```

因为只依赖前一个状态，可以用一个变量代替整个 `dp` 数组：

```java
int current = nums[0];
int result = nums[0];
for (int i = 1; i < nums.length; i++) {
    current = Math.max(nums[i], current + nums[i]);
    result = Math.max(result, current);
}
return result;
```

前面的实现提前将负数累加和清零，等价于 `max(0, dp[i - 1]) + nums[i]`，因此与这个状态转移一致。

## 复杂度

数组只遍历一次，时间复杂度为 `O(n)`；只使用固定数量的变量，额外空间复杂度为 `O(1)`。算法不会修改输入数组。
