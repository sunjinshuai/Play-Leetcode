# 56. 合并区间

给定区间数组 `intervals`，其中每个元素 `[start, end]` 表示一个闭区间。合并所有重叠区间，返回一组互不重叠、覆盖原输入所有区间的区间。

[力扣题目](https://leetcode.cn/problems/merge-intervals/) · [Java 源码](Java/Solution.java)

## 示例

| 输入 | 输出 | 说明 |
| --- | --- | --- |
| `[[1,3], [2,6], [8,10], [15,18]]` | `[[1,6], [8,10], [15,18]]` | 前两个区间重叠 |
| `[[1,4], [4,5]]` | `[[1,5]]` | 闭区间端点相接也需要合并 |
| `[[1,10], [2,6]]` | `[[1,10]]` | 后一个区间被前一个包含 |
| `[[8,10], [1,3], [2,6]]` | `[[1,6], [8,10]]` | 输入不一定有序 |
| `[[2,2]]` | `[[2,2]]` | 单个区间可以退化为一个点 |

本实现按题目非空输入的约定直接读取 `intervals[0]`；若用于允许空数组的场景，需要在读取前另行处理。

## 排序后维护一个正在合并的区间

先按左端点升序排序，再从左到右扫描。扫描过程中维护：

- `merged`：已经确定、不再与后续区间重叠的结果。
- `[left, right]`：正在合并、尚未加入结果的区间。

排序保证后续区间的起点不会更小。因此，只需比较当前遍历区间的起点与 `right`。

### 起点大于 right：保存旧区间，开启新区间

例如当前是 `[1,6]`，下一个是 `[8,10]`。因为 `8 > 6`，两个区间之间有空隙。

后续区间的起点都至少是 `8`，不可能再与 `[1,6]` 重叠，所以可以将 `[1,6]` 放入结果，然后把当前区间切换为 `[8,10]`。

### 起点不大于 right：合并并更新右端点

例如当前是 `[1,3]`，下一个是 `[2,6]`，合并后成为 `[1,6]`。

排序后，当前 `left` 不大于后续区间的起点，无需改变；右端点取两个右端点的最大值：

```java
right = Math.max(right, intervals[i][1]);
```

不能直接用后一个区间的右端点覆盖 `right`。对于 `[1,10]` 和 `[2,6]`，覆盖会错误地把结果缩成 `[1,6]`。

## Java 实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Solution {
    public int[][] merge(int[][] intervals) {
        List<int[]> merged = new ArrayList<>();
        Arrays.sort(intervals, (x, y) -> Integer.compare(x[0], y[0]));

        int left = intervals[0][0];
        int right = intervals[0][1];

        for (int i = 0; i < intervals.length; i++) {
            if (intervals[i][0] > right) {
                merged.add(new int[]{left, right});
                left = intervals[i][0];
                right = intervals[i][1];
            } else {
                right = Math.max(right, intervals[i][1]);
            }
        }

        // 最后一段没有后续区间触发保存，需要在遍历结束后补入。
        merged.add(new int[]{left, right});
        return merged.toArray(new int[merged.size()][]);
    }
}
```

`Integer.compare(x[0], y[0])` 比较两个区间的左端点，不需要使用可能溢出的整数减法。排序改变的是外层数组中各区间的排列顺序。

## 遍历过程

以 `[[1,3], [2,6], [8,10], [15,18]]` 为例，初始化 `[left, right] = [1,3]`：

| 遍历区间 | 操作 | 当前区间 | 已存入 merged |
| --- | --- | --- | --- |
| `[1,3]` | 与自身合并 | `[1,3]` | `[]` |
| `[2,6]` | `2 <= 3`，扩展右端点 | `[1,6]` | `[]` |
| `[8,10]` | `8 > 6`，保存旧区间 | `[8,10]` | `[[1,6]]` |
| `[15,18]` | `15 > 10`，保存旧区间 | `[15,18]` | `[[1,6], [8,10]]` |
| 遍历结束 | 补入最后一个区间 | — | `[[1,6], [8,10], [15,18]]` |

## 容易遗漏的细节

### 为什么是 >，不是 >=？

区间包含端点，`[1,3]` 与 `[3,5]` 在 `3` 处相交，应合并为 `[1,5]`。只有后一个区间的起点严格大于 `right`，才表示不重叠。

### 为什么循环后还要 add？

循环中只有遇到不重叠的下一个区间，才会保存当前区间。最后一段没有下一个区间触发保存，因此必须在循环后补入。所有区间都能合并时，也依赖这一步保存唯一的结果。

### 为什么循环从 0 开始也正确？

第一个区间已经用于初始化，从 `0` 开始只是多做一次与自身的合并，不影响答案。也可以将循环起点改为 `1`，省去这次重复比较。

### toArray 如何转换成二维数组？

`merged` 的每个元素都是一个表示区间的 `int[]`。`new int[merged.size()][]` 创建指定长度的外层数组，`toArray` 将列表中的 `int[]` 引用依次放入其中，最终得到 `int[][]`，无需预先指定内层长度。

结果区间由 `new int[]{left, right}` 创建，不复用输入的内层数组；算法不修改原区间的端点值，但会排序输入的外层数组。如果需要保留原排列，可以先浅拷贝外层数组再排序。

## 复杂度

设区间数量为 `n`。

- 时间复杂度：`O(n log n)`。排序为 `O(n log n)`，扫描与结果转换为 `O(n)`。
- 空间复杂度：`O(n)`。结果最多包含 `n` 个区间；Java 对这里的对象数组（元素为 `int[]`）进行比较器排序，也可能使用 `O(n)` 辅助空间，不能将整体额外空间记为 `O(1)`。
