# 59. 螺旋矩阵 II

给定正整数 `n`，生成一个 `n × n` 矩阵，把 `1` 到 `n²` 按顺时针螺旋顺序填入。

[力扣题目](https://leetcode.cn/problems/spiral-matrix-ii/description/) · [Java 源码](Java/Solution.java)

## 示例

```text
输入：n = 3
输出：[[1,2,3],[8,9,4],[7,6,5]]

1 → 2 → 3
        ↓
8 → 9   4
↑       ↓
7 ← 6 ← 5
```

## 思路：按圈模拟，使用左闭右开区间

矩阵按圈从外向内填。每一圈依次走顶边、右边、底边、左边；每条边都**包含起点，不包含转弯处的终点**。这样一个角留给下一条边填写，不会被重复覆盖。

这份实现用 `startX`、`startY` 表示当前圈左上角，用 `offset` 推导当前圈的右、下边界：

```text
当前圈左上角：(startX, startY)
当前圈右边界：n - offset
当前圈下边界：n - offset
```

下标从 0 开始。第一圈 `startX = startY = 0`、`offset = 1`，所以最右列、最下行的下标都是 `n - 1`。每完成一圈，起点向右下移动一格，`offset` 加一，右边界和下边界也随之向内收缩。

## 四条边如何避免重复

以 `n = 4` 为例，第一圈的右边界和下边界都是 `3`。

| 边 | 遍历下标 | 转弯角由谁填写 |
| --- | --- | --- |
| 顶边：从左到右 | `j = startY` 到 `n - offset - 1` | 右上角留给右边 |
| 右边：从上到下 | `i = startX` 到 `n - offset - 1` | 右下角留给底边 |
| 底边：从右到左 | `j = n - offset` 到 `startY + 1` | 左下角留给左边 |
| 左边：从下到上 | `i = n - offset` 到 `startX + 1` | 左上角留给顶边 |

例如第一圈：

1. 顶边填第一行的第 `0、1、2` 列；循环结束后 `j = 3`，停在右上角。
2. 右边使用这个 `j = 3`，从第 `0` 行填到第 `2` 行；结束后 `i = 3`，停在右下角。
3. 底边使用这个 `i = 3`，从第 `3` 列向左填到第 `1` 列；结束后 `j = 0`，停在左下角。
4. 左边使用这个 `j = 0`，从第 `3` 行向上填到第 `1` 行；结束后 `i = 0`，回到左上角。

所以四个角分别由顶边、右边、底边、左边各写一次。这里 `j` 和 `i` 在循环间传递转弯坐标：前一个 `for` 循环结束时的值，正好是下一条边开始使用的坐标。理解这段实现时，要特别留意 `for` 的第三部分执行后才会检查下一次条件，因此循环结束后变量会停在边界坐标上。

第一圈 `n = 4` 填完后，矩阵外圈如下，内圈尚未填写：

```text
 1   2   3   4
12   □   □   5
11   □   □   6
10   9   8   7
```

随后 `startX`、`startY`、`offset`、`loop` 各加一，开始处理内部的 `2 × 2` 区域。

## Java 实现

```java
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] nums = new int[n][n];
        int startX = 0;
        int startY = 0; // 每一圈左上角的起始位置
        int offset = 1;
        int count = 1;
        int loop = 1;
        int i = 0; // 行下标
        int j = 0; // 列下标

        while (loop <= n / 2) {
            // 顶边：左到右，不包含右上角
            for (j = startY; j < n - offset; j++) {
                nums[startX][j] = count++;
            }

            // 右边：上到下，不包含右下角
            for (i = startX; i < n - offset; i++) {
                nums[i][j] = count++;
            }

            // 底边：右到左，不包含左下角
            for (; j > startY; j--) {
                nums[i][j] = count++;
            }

            // 左边：下到上，不包含左上角
            for (; i > startX; i--) {
                nums[i][j] = count++;
            }

            startX++;
            startY++;
            offset++;
            loop++;
        }

        // 奇数阶矩阵剩下一个中心格
        if (n % 2 == 1) {
            nums[startX][startY] = count;
        }

        return nums;
    }
}
```

## 圈数与中心格

每个完整圈至少有两行、两列，因此完整圈数为 `n / 2`（整数除法）。`loop` 从 1 开始，故循环条件是 `loop <= n / 2`。

- `n = 4`：完整填两圈，没有中心格。
- `n = 3`：完整填一圈，之后单独填中心 `(1,1)`。
- `n = 1`：完整圈数为 0，循环跳过，直接把 `1` 填在 `(0,0)`。

奇数时，所有完整圈之后只剩一个中心格，`startX` 和 `startY` 都正好指向它，`count` 是尚未写入的下一个数字。

## 复杂度

- 时间复杂度：`O(n²)`，每个格子恰好写入一次。
- 额外空间复杂度：`O(1)`，不计返回矩阵；结果矩阵占用 `O(n²)` 空间。
