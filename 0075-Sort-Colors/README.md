# 75. 颜色分类

## 题意

数组里只有 `0、1、2`，把它们按从小到大的顺序排列，直接修改原数组，不能调用内置排序函数。[力扣原题](https://leetcode.cn/problems/sort-colors/)

例如：`[2, 0, 2, 1, 1, 0]` → `[0, 0, 1, 1, 2, 2]`。

## 最容易理解的解法：计数法

只做两件事：**先数个数，再按顺序填回去。**

例如，上面的数组中有两个 `0`、两个 `1`、两个 `2`，所以依次写入两个 `0`、两个 `1`、两个 `2` 就完成了排序。

```java
class Solution {
    public void sortColors(int[] nums) {
        int[] count = new int[3];
        for (int num : nums) {
            count[num]++;
        }

        int index = 0;
        for (int color = 0; color < 3; color++) {
            for (int i = 0; i < count[color]; i++) {
                nums[index++] = color;
            }
        }
    }
}
```

### 1. 为什么 `new int[3]` 中是 3？

因为题目中只有 **`0、1、2` 三种数字**，所以需要三个位置，分别记录它们出现的次数。刚创建时，三个位置的值默认都是 `0`：

```text
下标：    0  1  2
count： [0, 0, 0]
```

| 位置 | 含义 |
| --- | --- |
| `count[0]` | 数字 `0` 出现的次数 |
| `count[1]` | 数字 `1` 出现的次数 |
| `count[2]` | 数字 `2` 出现的次数 |

**长度是 `3`，下标是 `0、1、2`，没有 `count[3]`。** 这里的 `3` 与输入数组有多长无关，只与题目中的三种数字有关。

### 2. `count[num]++` 是什么意思？

`for (int num : nums)` 表示依次取出数组里的每一个数字。`count[num]++` 表示：**数字 `num` 出现了一次，把它对应的计数加 1。**

它等价于：

```java
count[num] = count[num] + 1;
```

下面统一用 `[2, 0, 2, 1]` 举例。最初 `count` 是 `[0, 0, 0]`，逐个读取数字：

| 读到的 `num` | 执行的代码 | 执行后的 `count` |
| --- | --- | --- |
| `2` | `count[2]++` | `[0, 0, 1]` |
| `0` | `count[0]++` | `[1, 0, 1]` |
| `2` | `count[2]++` | `[1, 0, 2]` |
| `1` | `count[1]++` | `[1, 1, 2]` |

最后 `count = [1, 1, 2]`，表示数字 `0` 出现了 1 次，数字 `1` 出现了 1 次，数字 `2` 出现了 2 次。

记住：**下标表示“哪个数字”，里面的值表示“出现了几次”。**

### 3. 统计完次数，是不是已经排好序了？

**还没有。第一个循环只修改了 `count`，没有修改原数组 `nums`。**

```java
for (int num : nums) {
    count[num]++;
}
```

执行完后：

```text
nums  = [2, 0, 2, 1]  ← 原数组没变，还没有排好序
count = [1, 1, 2]     ← 记录的是各个数字的次数
```

`count` 的下标本来就是 `0、1、2`，看起来有顺序，但它存的是次数，不是排序结果。

还需要根据次数，向 `nums` 中依次填入 1 个 `0`、1 个 `1`、2 个 `2`，才能得到 `[0, 1, 2, 2]`。

### 4. 后面的两个 for 循环如何填回数字？

**外层决定填哪个数字，内层决定填几次。** `index` 记录填到 `nums` 的哪个位置。

```java
int index = 0;
for (int color = 0; color < 3; color++) {
    for (int i = 0; i < count[color]; i++) {
        nums[index++] = color;
    }
}
```

其中 `nums[index++] = color` 相当于：

```java
nums[index] = color; // 先在当前位置填入数字
index++;            // 再移动到下一个位置
```

继续使用统计后的状态：

```text
nums  = [2, 0, 2, 1]
count = [1, 1, 2]
index = 0
```

#### 第一轮：color = 0，填入数字 0

因为 `count[0] = 1`，内层循环执行一次：

```java
// i = 0，满足 i < 1
nums[0] = 0;
index++; // index 从 0 变成 1
```

此时数组变成：

```text
nums = [0, 0, 2, 1]
        ↑
        刚填好的位置
```

接着 `i` 变成 `1`，不满足 `i < 1`，内层循环结束。此时只有第一个位置填好了，后面三个位置还没有重新填写。

#### 第二轮：color = 1，填入数字 1

因为 `count[1] = 1`，内层循环也执行一次。`i` 重新从 `0` 开始，但 **`index` 接着上次的 `1` 继续**，不会回到 `0`。

```java
// i = 0，满足 i < 1
nums[1] = 1;
index++; // index 从 1 变成 2
```

此时数组变成：

```text
nums = [0, 1, 2, 1]
           ↑
           刚填好的位置
```

接着 `i` 变成 `1`，不满足 `i < 1`，内层循环结束。

#### 第三轮：color = 2，填入数字 2

因为 `count[2] = 2`，内层循环执行两次：

```java
// i = 0，满足 i < 2
nums[2] = 2;
index++; // index 从 2 变成 3

// i = 1，满足 i < 2
nums[3] = 2;
index++; // index 从 3 变成 4
```

数组依次变成：

```text
[0, 1, 2, 1]  ← 在下标 2 写入 2，恰好与原值相同
[0, 1, 2, 2]  ← 在下标 3 写入 2
```

随后 `i = 2`，不再满足 `i < 2`，内层循环结束。接着 `color` 变成 `3`，不再满足 `color < 3`，外层循环也结束。

`index` 最后等于数组长度 `4`，表示已经填完四个位置；循环已经结束，不会再访问不存在的 `nums[4]`。

#### 三个变量有什么区别？

| 变量 | 负责什么 | 本例的变化 |
| --- | --- | --- |
| `color` | 这轮填哪个数字 | 依次处理 `0、1、2`，到 `3` 时结束 |
| `i` | 这轮已经填了几个 | 每换一种数字，都从 `0` 开始 |
| `index` | 下一个要填写的位置 | 一直往后走，`0 → 1 → 2 → 3 → 4` |

如果某种数字的次数是 `0`，内层循环一开始就不满足 `i < count[color]`，直接跳过。

所有次数相加恰好等于数组长度，所以每个位置都会被填好。**先填完所有 `0`，再填所有 `1`，最后填所有 `2`，数组就有序了。**

## 复杂度与边界

- 时间复杂度：`O(n)`。统计访问 `n` 个元素，填回也写入 `n` 个元素。虽然填回使用了两层循环，但总共只写 `n` 次。
- 额外空间复杂度：`O(1)`。计数数组始终只有三个位置，不随输入长度增长。
- 只有一个元素、全部相同或缺少某一种数字时，都能正常处理。

此解法满足基本题意；题目进阶要求“一趟扫描”，计数法需要两遍遍历，不满足该进阶要求。
