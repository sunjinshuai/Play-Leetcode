# 142. 环形链表 II

给定单链表的头节点 `head`，返回环的入口节点；如果没有环，返回 `null`。不能修改链表。

[力扣题目](https://leetcode.cn/problems/linked-list-cycle-ii/) · [Java 集合解法](Java/Solution.java) · [Java 快慢指针解法](Java/TwoPointers/Solution.java)

题目中的 `pos` 表示链表尾部连接到的节点索引，仅用于描述测试数据，不会传给 `detectCycle`。方法返回节点对象，而不是节点值或索引。

## 哈希集合

沿着 `next` 向后走，用集合记录已经访问过的节点：

1. 当前节点不在集合里：加入集合，继续向后走。
2. 当前节点已经在集合里：返回这个节点，它就是环的入口。
3. 走到 `null`：说明没有环，返回 `null`。

### 为什么第一次重复的节点就是入口？

进入环之前，路径上的节点不会重复。进入环后，沿着 `next` 绕一圈，最先再次遇到的就是入口节点。

```text
3 → 2 → 0 → -4
    ↑         │
    └─────────┘
```

访问顺序是 `3 → 2 → 0 → -4 → 2 → …`：

| 当前节点 | 是否已经访问 | 操作 |
| --- | --- | --- |
| 3 | 否 | 加入集合 |
| 2 | 否 | 加入集合 |
| 0 | 否 | 加入集合 |
| -4 | 否 | 加入集合 |
| 2（同一个节点） | 是 | 返回该节点 |

### Java 集合实现

源码使用力扣提供的 `ListNode`，其成员为 `int val` 和 `ListNode next`。

```java
import java.util.HashSet;
import java.util.Set;

public class Solution {
    public ListNode detectCycle(ListNode head) {
        Set<ListNode> seen = new HashSet<ListNode>();
        while (head != null) {
            if (seen.contains(head)) {
                return head;
            } else {
                seen.add(head);
            }
            head = head.next;
        }
        return null;
    }
}
```

### 比较节点身份，不比较值

题目提供的 `ListNode` 没有重写 `equals` 和 `hashCode`，因此 `HashSet<ListNode>` 按对象身份判断是否为同一个节点。两个不同节点即使 `val` 相同，也不能判定有环，不能改用 `Set<Integer>` 保存节点值。

### 移动 head 不会修改链表

`head = head.next` 只改变方法内局部变量指向的节点，没有修改任何节点的 `next`，也不会改变调用方变量指向的节点。

### 集合解法的边界情况

- 空链表：不进入循环，返回 `null`。
- 单节点且无环：访问一次后到达 `null`，返回 `null`。
- 单节点指向自身：第二次访问时返回该节点。
- 环入口就是头节点：绕环一圈后返回头节点。
- 多个节点值相同但无环：仍返回 `null`。

### 集合解法的复杂度

设从头节点能够到达的不同节点数为 `n`。

- 时间复杂度：`O(n)`，按哈希集合插入和查询平均 `O(1)` 计算。
- 额外空间复杂度：`O(n)`，集合保存已访问节点的引用，不复制节点。

## 快慢指针

快慢指针分为两个阶段：先判断是否有环，再寻找环的入口。两份 Java 源码均使用力扣提供的 `ListNode`，分别独立提交。

### 第一阶段：找到环内的相遇点

`slow` 和 `fast` 都从 `head` 出发，每轮 `slow` 走一步，`fast` 走两步。

- 没有环：快指针到达链表末尾，返回 `null`。
- 存在环：两者最终都进入环，此后快指针每轮相对慢指针多走一步，最终一定追上慢指针。

初始时两者都在头节点，必须先移动，再比较是否相遇。这里比较节点对象，使用 `fast == slow`。第一次相遇的位置不一定是入口。

### 第二阶段：同速前进，找到入口

第一次相遇后，让指针 `p` 从 `head` 出发，`slow` 留在相遇点。两个指针每轮都走一步，首次相遇的位置就是入口。

```text
A → B → C → D → E
        ↑       │
        └───────┘
```

第一阶段：

| 移动轮数 | slow（每轮一步） | fast（每轮两步） |
| --- | --- | --- |
| 0 | A | A |
| 1 | B | C |
| 2 | C | E |
| 3 | D | D |

第一次在 `D` 相遇。第二阶段让 `p` 回到 `A`，`slow` 留在 `D`：

| 移动轮数 | p（每轮一步） | slow（每轮一步） |
| --- | --- | --- |
| 0 | A | D |
| 1 | B | E |
| 2 | C | C |

两个指针在入口 `C` 相遇。

### 为什么第二阶段一定在入口相遇？

定义三个距离，均以沿 `next` 移动的步数计算：

- `a`：头节点到环入口的距离。
- `b`：从环入口沿 `next` 到第一次相遇点的距离，`0 ≤ b < L`。
- `L`：环长。

```text
头节点 ── a 步 ──→ 环入口 ── b 步 ──→ 相遇点
                      ↑                  │
                      └──────────────────┘
```

**1. 慢指针的路程。** 假设慢指针在第一次相遇前，进入环后绕过 `m` 个完整圈，走过的总步数为：

```text
s = a + b + mL
```

**2. 快慢指针的路程差。** 快指针走了 `2s` 步，比慢指针多走 `s` 步。两者从同一起点出发，在环内同一个节点相遇，所以路程差是环长的正整数倍，记为 `kL`：

```text
2s - s = kL
s = kL
```

将慢指针的路程代入并整理：

```text
a + b + mL = kL
a + b = (k - m)L
```

因此，`a + b` 恰好是环长的整数倍。

**3. 从相遇点再走 a 步。** 相遇点在入口前进 `b` 步的位置，再走 `a` 步，相当于从入口走了 `b + a` 步。这是完整的若干圈，所以恰好回到入口。

与此同时，从头节点出发的 `p` 走了 `a` 步，也恰好到达入口。在这之前，`p` 还在环外，`slow` 始终在环内，它们不可能提前相遇。因此第二阶段第一次相遇就是入口。

注意：`a` 不一定等于相遇点到入口的最短距离，可能多出若干个完整圈。若 `a = 0`，则 `b = 0`，头节点就是入口和第一次相遇点，第二阶段无需移动。

### Java 快慢指针实现

```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode fast = head;
        ListNode slow = head;

        while (fast != null && fast.next != null) {
            fast = fast.next.next;
            slow = slow.next;

            if (fast == slow) {
                ListNode p = head;
                while (p != slow) {
                    p = p.next;
                    slow = slow.next;
                }
                return p;
            }
        }
        return null;
    }
}
```

### 容易写错的地方

1. **从当前位置继续走。** 应写 `fast = fast.next.next`、`slow = slow.next`。写成 `head.next.next` 和 `head.next` 会让每轮都停留在固定位置，无法持续向前推进。
2. **检查 `fast.next`。** 快指针走两步前，需要保证 `fast != null && fast.next != null`；只检查 `slow != null` 无法防止访问空的 `fast.next`。
3. **第一次相遇不能直接返回 `head`。** 此时只能确定有环，还需要第二阶段寻找入口。
4. **第二阶段先判断，再移动。** 当入口是头节点时，`p` 和 `slow` 已经相同，直接返回即可。

### 快慢指针的复杂度与边界

设可达的不同节点数为 `n`。第一阶段进入环后至多再经过一圈就相遇，第二阶段走 `a` 步，因此时间复杂度为 `O(n)`。只使用固定数量的指针，额外空间为 `O(1)`。

空链表和无环单节点不会进入第一阶段循环，返回 `null`。单节点自环在移动一轮后相遇，第二阶段直接返回该节点。不同节点的值可以重复，两阶段均按对象身份比较。算法只移动局部引用，不修改节点值或 `next`。

## 两种解法对比

| 解法 | 时间复杂度 | 额外空间 | 如何定位入口 |
| --- | --- | --- | --- |
| 哈希集合 | 平均 `O(n)` | `O(n)` | 第一次重复访问的节点 |
| 快慢指针 | `O(n)` | `O(1)` | 相遇后，一个回头，两者同速前进 |
