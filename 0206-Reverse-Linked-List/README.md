# 206. 反转链表

给定单链表的头节点 `head`，原地反转每个节点的指向，返回新的头节点。

[力扣题目](https://leetcode.cn/problems/reverse-linked-list/) · [Swift 源码](Swift/Solution.swift)

## 迭代反转

`pre` 指向已反转部分的头节点，初始为 `nil`。`cur` 指向下一个待处理的节点，初始为 `head`。

1. 用 `next` 保存当前节点原来的后继，反转后还能继续访问剩下的节点。
2. 将当前节点的 `next` 指向 `pre`。
3. 将 `pre` 移到当前节点，将 `cur` 移到保存的后继节点。

当 `cur` 为 `nil` 时，返回 `pre`。空链表会跳过循环并返回 `nil`。Swift 源码使用力扣提供的 `ListNode`。

## 示例

输入 `1 → 2 → 3 → nil`，输出 `3 → 2 → 1 → nil`。

第一轮先保存节点 `2`，再让 `1.next` 指向 `nil`。此时 `pre` 指向节点 `1`，`cur` 指向节点 `2`。后两轮依次将节点 `2` 和 `3` 接到已反转部分的头部。

## 复杂度

每个节点访问一次，时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。
