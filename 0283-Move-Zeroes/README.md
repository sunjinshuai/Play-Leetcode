# 283. 移动零

## 题意与示例

原地修改整数数组 `nums`，将所有零移到末尾，同时保持非零元素的相对顺序。[力扣原题](https://leetcode.cn/problems/move-zeroes/)

| 输入 `nums` | 修改后的 `nums` |
| --- | --- |
| `[0, 1, 0, 3, 12]` | `[1, 3, 12, 0, 0]` |
| `[0]` | `[0]` |

## Java 双指针

`right` 从左到右扫描数组，`left` 指向下一个非零元素该放的位置。两个指针都从下标 `0` 开始。

1. 如果 `nums[right]` 是零，只将 `right` 右移一格。
2. 如果 `nums[right]` 非零，调用 `swap(nums, left, right)`，然后将两个指针各右移一格。两个指针重合时，元素与自身交换，`left` 仍需前进。

每轮开始时，`left` 左边是已经按原顺序放好的非零元素，`[left, right)` 里的元素全是零。因此当 `left < right` 时，交换会把当前非零元素放到前面，并把零换到扫描位置。由于 `right` 按原顺序遇到每个非零元素，它们的相对顺序得以保留。

以 `[0, 1, 0, 3, 12]` 为例，表中记录了每轮结束后的指针和数组状态。

| 本轮 `right` | 读到的数 | 操作 | `left` 变化 | 下一轮 `right` | 操作后的数组 |
| --- | --- | --- | --- | --- | --- |
| `0` | `0` | 跳过 | `0 → 0` | `1` | `[0, 1, 0, 3, 12]` |
| `1` | `1` | 交换下标 `0` 和 `1` | `0 → 1` | `2` | `[1, 0, 0, 3, 12]` |
| `2` | `0` | 跳过 | `1 → 1` | `3` | `[1, 0, 0, 3, 12]` |
| `3` | `3` | 交换下标 `1` 和 `3` | `1 → 2` | `4` | `[1, 3, 0, 0, 12]` |
| `4` | `12` | 交换下标 `2` 和 `4` | `2 → 3` | `5` | `[1, 3, 12, 0, 0]` |

当 `right` 到达数组长度时，循环结束，`[left, nums.length)` 中剩下的元素都是零。

设数组长度为 `n`。遍历一次数组，每次交换耗时为常数，时间复杂度为 `O(n)`。原地交换只用到两个指针和临时变量，额外空间复杂度为 `O(1)`。
