# 509. 斐波那契数

## 题目描述

给定整数 `n`（`0 ≤ n ≤ 30`），求第 `n` 个斐波那契数。数列从 `0` 和 `1` 开始，其余各项为前两项之和。

```text
F(0) = 0, F(1) = 1
F(n) = F(n - 1) + F(n - 2)，其中 n > 1
```

## 示例

### 示例 1

```text
输入：2
输出：1
解释：F(2) = F(1) + F(0) = 1 + 0 = 1.
```

### 示例 2

```text
输入：3
输出：2
解释：F(3) = F(2) + F(1) = 1 + 1 = 2.
```

### 示例 3

```text
输入：4
输出：3
解释：F(4) = F(3) + F(2) = 2 + 1 = 3.
```
